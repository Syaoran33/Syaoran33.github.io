域名选择方案

First Post:

方案一：免费三级域名

申请地址

DNSHE 提供免费二级域名分发，可注册最多 5 个三级域名。

可用主域名

主域名 后缀
cc.cd 简短好记
ccwu.cc 个人风格
bbroot.com 技术感

优点

  • 零成本，适合练手、个人项目、临时服务
  • 注册快，即时生效，不需要审核
  • 无需备案，绑定境外服务器即可直接访问

缺点

  • 所有权不完整——你拥有的是三级域名（如 yourname.cc.cd），主域名归平台所有，平台跑路或被回收域名就没了
  • 限制多——最多 5 个，DNS 解析功能可能有限
  • 信任度低——邮箱、支付类服务不建议用免费域名，容易被拒
  • SEO 不友好——搜索引擎对免费域名的权重较低

方案二：国内购买顶级域名

供应商

  • 阿里云
  • 腾讯云
  • 华为云

推荐后缀

后缀 价格（首年） 说明
.top ~¥6-10 性价比最高，推荐
.xyz ~¥8 常见便宜域名
.cn ~¥30 国内专用，必须实名
.com ~¥60 国际通用，较贵

名称建议

  • 4-5 位字母，如 abcd.top、devco.top
  • 纯数字组合，不介意的话可以直接在域名交易平台一口价购买，常有便宜的纯数字短域名（如 12345.top 可能只要几十块）
  • 避免生僻词、连字符

优点

  • 拥有完整所有权，可自由转移、续费
  • 专业可信，适合商业项目、个人品牌
  • DNS 功能完善，支持子域名、解析记录、CDN 接入
  • 可备案——国内服务器的前提

缺点

  • 需要实名认证（身份证 + 人脸）
  • 需要续费（每年），忘记续费可能被抢注
  • 备案流程——绑定国内服务器必须备案（详见下文）

备案说明

用国内服务器（阿里云 ECS、腾讯云轻量等）且域名解析到国内 IP，必须 ICP 备案。

流程：

  1. 购买域名 → 实名认证（1-3 天）
  2. 购买国内服务器（至少 3 个月有效期）
  3. 提交备案申请（阿里云/腾讯云 App 操作）
  4. 填写网站信息、负责人信息、上传身份证
  5. 管局审核（7-20 个工作日）
  6. 拿到备案号 → 部署上线

如果不想备案：买香港或海外的服务器（如 LightSail、Vultr），域名不用备案即可访问，但延迟略高。

绑定 Cloudflare（免费 CDN + DNS）

无论用哪种域名，都推荐套上 Cloudflare——免费、加速、隐藏源站 IP。

第一步：注册 Cloudflare

  • 打开 https://dash.cloudflare.com/sign-up
  • 邮箱注册，验证后登录

第二步：添加站点

  • 在 Cloudflare 首页点击 Add a site
  • 输入你的域名（如 example.top）
  • 选择 Free 计划（免费够用）
  • 等待 Cloudflare 扫描现有 DNS 记录

第三步：修改 DNS 服务器

Cloudflare 会给出两个 Nameserver 地址，例如：

去你的域名注册商处修改：

注册商 操作位置
阿里云 域名管理 → DNS修改 → 修改DNS服务器
腾讯云 域名管理 → DNS 服务器
DNSHE 域名管理 → 修改 DNS 服务器

⚠️ 注意：在 DNSHE 免费域名中，只有部分主域名支持自定义 DNS，如果不支持就无法使用 Cloudflare。

第四步：配置解析记录

回到 Cloudflare → DNS → Records，添加：

类型 名称 内容 说明
A @ 服务器 IP 根域名指向服务器
CNAME www 你的域名 www 转发到根域名
CNAME blog 你的域名 子域名博客

小云朵图标（Proxy）点亮 → 启用 Cloudflare CDN 和隐藏 IP。

第五步：SSL/TLS

Cloudflare → SSL/TLS → 选择 Full (strict)：

  • 需要源站配置有效 SSL 证书（可用 acme.sh 或 Certbot 免费申请）
  • 如果源站没证书，选 Flexible（Cloudflare 到访客 HTTPS，到服务器 HTTP）

第六步：自动跳转 HTTPS

SSL/TLS → Edge Certificates → 开启 Always Use HTTPS。

第七步：等待生效

修改 DNS 后最长 24-48 小时生效，通常在 几分钟到几小时 内。

验证生效：

免费计划注意点

  • 流量不限，但单文件上传限制 100MB
  • 不支持 HTTP/3（免费版）
  • 中国大陆无节点，国内访问速度不会提升，但海外访问有明显加速
  • 如果服务器在国内，Cloudflare 反而会减速（绕路海外），此时建议不用 Cloudflare 或仅用 DNS（关闭 Proxy）
